# 별동 (S017~S019)

부지 반대편 구역(y≈30 부근). 스캔 3개를 정합해 병합했다.

- 점 개수: **1,185만**
- 정합 정확도: 다른 스캔까지 최근접 거리 **중앙값 7.0cm** (5cm 이내 36.6%)
- 좌표계: 현장 좌표계 (본체와 동일)

**본체보다 품질이 낮다.** 스캔이 3개뿐이라 상호 커버리지가 얇고, 한 스캔만
본 영역이 많다. 정합 자체는 신뢰할 만하지만(에지 rmse 16~20mm, 삼각 순환
위반 0) 본체 수준(2.6cm)을 기대하긴 어렵다.
→ 개선하려면 **이 구역 스캔을 추가 촬영**하는 것이 확실한 방법이다.

### 실측 비교

| 메시 | 정확도(중앙/95%) | 완전성(중앙/95%) | 바깥향 | 감김 |
|---|---|---|---|---|
| `Mesh_annex_poisson.ply` | 15.3 / 38mm | **8.5 / 22mm** | **83.0%** | **True** |
| `Mesh_annex_2cm.ply` | 15.3 / **32mm** | 9.4 / 19mm | 78.5% | False |
| `Mesh_annex.ply` (5cm) | 25.2 / 74mm | 13.2 / 31mm | 77.3% | False |

- **정확도** = 메시 표면에서 실측 점까지 거리. 지어낸 표면이 많으면 커진다.
- **완전성** = 실측 점에서 메시 표면까지 거리. 구멍이 많으면 커진다.

Poisson과 마칭 큐브 2cm는 충실도가 거의 동률이고, Poisson이 위상 품질에서
앞선다. 10cm판은 확연히 거칠어 미리보기용으로만 쓸 것.

## 02_메시/비교실험/

**실사용 파일이 아니다.** Poisson 트리밍 방식을 정하려고 만든 것으로,
판단 근거로 남겨 두었다.

| 파일 | 설정 | 결과 |
|---|---|---|
| `Mesh_annex_poisson_d12_밀도7.ply` | depth 12, 밀도 하위 7% 제거 | 지어낸 면이 남음. 정확도 95% **145mm** |
| `Mesh_annex_poisson_d13_밀도20.ply` | depth 13, 밀도 하위 20% 제거 | 정확도는 최고(9.4mm)지만 완전성 95% **1,689mm** |
| `Mesh_annex_poisson_d12_밀도35.ply` | depth 12, 밀도 하위 35% 제거 | 완전성 95% **1,870mm** |

### 여기서 배운 것

**Poisson의 밀도 백분위 트리밍을 LiDAR에 그대로 쓰면 안 된다.**

Poisson은 닫힌 표면을 만들려고 안 본 영역까지 지어내므로 잘라내야 한다.
보통은 재구성이 내놓는 정점 밀도로 자르는데, LiDAR는 **원거리일수록 점밀도가
낮다.** 그래서 "멀지만 실제로 측정된 면"이 저밀도로 분류돼 함께 잘려나간다.

위 표에서 밀도 20% 트리밍판은 정확도 중앙값이 9.4mm로 제일 좋아 보이지만,
완전성 95%가 1,689mm다. 실측 데이터가 있는 곳에 1.7m짜리 구멍이 뚫렸다는 뜻이다.
**중앙값만 보면 속는다.**

→ 채택한 방식은 밀도가 아니라 **실측점까지의 거리로 트리밍**(5cm)하는 것이다.
원거리 저밀도 면이 보존된다. `Mesh_annex_poisson.ply`가 그 결과다.
