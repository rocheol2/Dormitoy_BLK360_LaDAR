# 02_성과품 — 무엇이 들어 있나

정합 완료 점군과 3D 메시. 촬영 구역이 둘로 나뉘어 그룹별로 폴더가 있다.

```
02_성과품/
├── 본체_S003-S016/      스캔 14개, 부지 주요부
│   ├── 01_점군/
│   └── 02_메시/
└── 별동_S017-S019/      스캔 3개, 부지 반대편(y≈30 구역)
    ├── 01_점군/
    ├── 02_메시/
    └── 02_메시/비교실험/   방식 비교용, 실사용 아님
```

## 왜 둘로 나뉘어 있나

두 구역은 서로 겹침이 부족해 하나의 정합 그래프로 묶이지 않는다.
억지로 한 좌표계에 넣으면 별동이 어긋난 채 병합되므로 각각 정합했다.

다만 **두 그룹은 같은 현장 좌표계**를 쓴다. 뷰어에서 함께 열면 대략 겹친다.
정밀하게 하나로 합치려면 두 구역을 모두 보는 연결 스캔을 추가 촬영해야 한다.

## S002는 왜 없나

미정합 스캔이라 제외했다. 헤더 pose가 원점·무회전인 기본값이고, 0.7m 옆
S003과의 겹침이 0.8%뿐이다. 47만 점짜리 부분 스캔(전체의 0.9%)이라 손실은 작다.
근거는 [작업보고서](../03_설명자료/작업보고서.md) §4.

## 정합 품질

| | 본체 | 별동 |
|---|---|---|
| 다른 스캔까지 최근접 거리 중앙값 | **2.6 cm** | **7.0 cm** |
| 5cm 이내 일치 | 86.3% | 36.6% |
| 스캔 수 | 14 | 3 |

별동이 낮은 것은 스캔 3개뿐이라 상호 커버리지가 얇기 때문이다.
정합 자체는 신뢰할 만하지만(에지 rmse 16~20mm, 삼각 순환 위반 0) 본체 수준을
기대하긴 어렵다. 개선하려면 해당 구역 추가 촬영이 필요하다.

**이 수치는 스캔 간 상대 일치도다.** 절대 정확도가 필요하면 타깃이나 측량
기준점 기반 검증이 별도로 필요하다.
