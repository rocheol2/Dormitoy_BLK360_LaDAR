각각을 **3D 메시**로 변환한 결과물이다.

### 점군

| | 본체 | 별동 |
|---|---|---|
| E57 (원본 해상도, 스캔 블록 유지) | 690 MB | 216 MB |
| PLY (원본 해상도) | 615 MB | 192 MB |
| 미리보기 PLY (2cm) | 166 MB | 23 MB |

색상(RGB)·강도(intensity) 보존. **E57을 우선 쓸 것** — 스캔 블록 구조가
남아 있어야 메시의 법선 안/밖을 정할 수 있다.

### 3D 메시

| 메시 | 면 | 평균 모서리 | 크기 |
|---|---|---|---|
| **본체 `Mesh_main_poisson.ply`** | 5,139만 | 16.2 mm | 1,011 MB |
| 본체 `Mesh_main_2cm.ply` | 6,874만 | 19.1 mm | 1,370 MB |
| 본체 `Mesh_main.ply` (5cm) | 1,185만 | 48.0 mm | 237 MB |
| **별동 `Mesh_annex_poisson.ply`** | 1,090만 | 13.5 mm | 215 MB |
| 별동 `Mesh_annex_2cm.ply` | 979만 | 19.5 mm | 198 MB |
| 별동 `Mesh_annex.ply` (5cm) | 224만 | 48.6 mm | 45 MB |

**Poisson 판을 권장한다.** 본체 기준 삼각형을 25% 적게 쓰고도 더 정확하며
(정확도 중앙 12.9 vs 14.0mm), 감김 일관성과 법선 방향도 낫다.

| 용도 | 권장 |
|---|---|
| 일반적인 용도, 정밀 검토, 단면 추출 | **Poisson 판** |
| 전체 조망, 공유, 뷰어에서 회전/이동 | 5cm 판 |

**메시 사용 시 주의**

- **닫힌 솔리드가 아니다.** 스캔이 보지 못한 면(지붕 위, 가구 뒤)은 구멍으로
  남는다. 부피 계산·불리언 연산·3D 프린팅에는 별도 구멍 메우기가 필요하고,
  시각화·단면 추출·면적/거리 계측에는 그대로 쓸 수 있다.
- **더 잘게 만들 이유가 없다.** 점간격은 2~6mm로 충분히 조밀하지만 정합
  정확도가 본체 2.6cm / 별동 7.0cm다. 더 잘게 하면 정밀해지는 게 아니라
  정합 오차가 표면 요철로 재현된다.
